## 技能集成说明

### 与Stage 9集成

在Stage 9（运镜系统）完成后，根据镜头元数据自动匹配技能：

```javascript
// Stage 9 输出示例
const stage9Output = {
  camera: "medium_shot",        // 中景
  mood: "professional_trust",    // 专业信任
  lighting: "soft_natural",      // 柔和自然光
  subject: "doctor_explanation"  // 医生讲解
};

// 匹配技能
const matchedSkills = [
  "documentary_interview_medium_shot",      // 专业访谈中景
  "documentary_doctor_explanation_medium",   // 医生讲解中景
  "documentary_soft_natural_lighting"       // 柔和自然光
];
```

### 技能增强逻辑

1. **读取技能文件**: 从技能库读取匹配的技能内容
2. **提取关键词**: 提取技能中的电影级关键词（镜头术语、情绪词、禁止词）
3. **追加到提示词**: 将关键词追加到 `_generatedPrompt` 末尾
4. **确保不被丢弃**: 增强后的提示词写入 `stages.style.prompt` 字段
