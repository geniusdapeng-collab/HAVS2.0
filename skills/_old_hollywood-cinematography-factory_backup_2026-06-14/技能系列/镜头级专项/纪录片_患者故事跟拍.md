## 第二部分：患者故事跟拍的技术执行

### 技术参数

- 运镜：平滑跟拍（斯坦尼康/滑轨）
- 距离：中近景切换
- 稳定性：中（有呼吸感但不晃动）
- 焦点：跟焦（焦点随主体移动）
- 视角：平视（与患者同高度）
- 时长：20-45秒

### 光线设计

1. **环境光优先**: 医院走廊自然光 = 真实环境
2. **补光柔和**: 只在必要时补光 = 不破坏真实感
3. **色温自然**: 匹配环境色温 = 不突兀
4. **阴影保留**: 保留自然阴影 = 真实层次

## 第四部分：患者故事跟拍的医疗科普适配

### 医疗科普特殊考量

**医疗科普的"共情"设计：**
- 初诊场景：跟随患者进入医院 → "我也经历过..."
- 检查场景：跟拍检查过程 → "原来是这样..."
- 治疗场景：记录治疗日常 → "我能理解..."
- 康复场景：跟随康复训练 → "希望在前方..."

**医疗科普的情绪弧线：**
1. **好奇**: 跟随患者 → "他怎么了？"
2. **解释**: 记录过程 → "原来如此..."
3. **紧张**: 真实紧张 → "我也担心..."
4. **警示**: 严重后果 → "要重视..."
5. **安抚**: 康复希望 → "会好起来的..."
