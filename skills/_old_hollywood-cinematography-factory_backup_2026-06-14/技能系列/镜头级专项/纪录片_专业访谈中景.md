## 第二部分：专业访谈中景的技术执行

### 技术参数

- 构图：中景（腰部以上）
- 角度：平视（略低5-10度增强权威感）
- 稳定性：高（三脚架固定）
- 背景：简洁专业（书架/医疗设备/白墙）
- 景深：浅景深（背景虚化）
- 时长：15-30秒

### 光线设计

1. **三点布光**: 主光+辅光+轮廓光 = 专业访谈
2. **柔和主光**: 柔光箱/蝴蝶布 = 柔和专业
3. **背景光**: 分离背景 = 层次感
4. **眼神光**: 眼神中的亮点 = 生命力

### 医疗科普特殊考量

**医疗科普的"信任"设计：**
- 专家讲解：专业访谈中景建立"权威感"

- 专业背书：简洁背景建立"专注感"

**医疗科普的情绪弧线：**
1. **好奇**: 专业访谈开场 → "这位专家是谁？"
2. **解释**: 权威讲解 → "专家这么说..."
3. **紧张**: 严肃警示 → "专家警告..."
4. **警示**: 权威呼吁 → "必须重视！"
5. **安抚**: 专业安慰 → "专家说可以..."
