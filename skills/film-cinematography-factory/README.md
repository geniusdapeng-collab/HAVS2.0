# Film Cinematography Skill Factory

> **版本**: v2.0.0  
> **更新**: 2026-06-14  
> **适配系统**: 卓越视频系统 v6.5+  
> **技能数量**: 15+ 核心技能（覆盖纪录片、剧情片、广告片、品牌片、科普片等）

## 核心定位

**本系统只影响外在影视表现模块**，不触碰剧本内容、事实准确性或叙事逻辑。

| 受影响的维度 | 不受影响的维度 |
|------------|-------------|
| 影视风格（导演风格、色调、质感） | 剧本内容、台词、叙事逻辑 |
| 运镜设计（镜头运动、构图、景别） | 事实准确性、医学知识、数据 |
| 灯光设计（布光方案、色温、氛围） | 人物设定、角色关系 |
| 美术布景（场景氛围、道具风格、环境） | 品牌信息、产品描述 |

## 影片类型分类

### 1. 纪录片/纪实类（Documentary）
- 维伦纽瓦冥想手持
- 专业访谈中景
- 柔和自然光
- 患者故事跟拍
- 冷静专业特写
- 环境全景
- 情感连接特写
- 医学示意图动画
- 温暖治愈近景

### 2. 剧情片/故事类（Drama）
- 正反打对话
- 主观镜头（POV）
- 戏剧性灯光（明暗对比）
- 情绪特写
- 环境氛围建立
- 运动镜头调度

### 3. 广告片/商业类（Commercial）
- 产品英雄特写（Hero Shot）
- 动态展示运镜
- 高质感灯光
- 生活方式场景
- 品牌色调强化

### 4. 品牌片/企业类（Brand）
- 环境氛围全景
- 人物 testimonial 中景
- 现代简洁灯光
- 空间美学构图
- 质感细节特写

### 5. 通用技能（Universal）
- 黄金时刻灯光
- 戏剧性明暗对比
- 平滑斯坦尼康运动
- 浅景深人像
- 建筑几何构图
- 微距细节
- 航拍/无人机视角
- 慢动作诗意
- 快速剪辑节奏
- 一镜到底长镜头

## 技能集成说明

### 与 Stage 8.4 集成

在 Stage 9（运镜系统）之后，Stage 8.4（技能注入）之前：

```javascript
// 输入：影片类型 + 镜头元数据
const input = {
  filmType: 'documentary',        // 影片类型
  camera: 'medium_shot',          // 景别
  mood: 'professional_trust',     // 情绪
  lighting: 'soft_natural',       // 灯光
  subject: 'explanation'        // 主体
};

// 输出：增强后的 prompt（只影响外在表现）
const enhancedPrompt = injectFilmicSkills(basePrompt, input, {
  injectTargets: ['style', 'camera', 'lighting', 'artDirection'],  // 只影响这些维度
  contentSafe: true  // 确保不修改内容、事实、叙事
});
```

### 注入安全边界

1. **只追加不替换**：技能术语追加到 prompt 末尾，不替换原有内容
2. **内容隔离**：禁止修改 SCENE、STORY、CHARACTER、DIALOGUE 等段落
3. **事实保护**：禁止修改医学术语、数据、品牌信息、产品描述
4. **维度锁定**：只影响 RENDER、CAMERA、LIGHTING、ART_DIRECTION 等外在维度
