# 技能：反射映射（Reflective Mapping）

> **技能ID**: `lighting-reflective-mapping`
> **版本**: v1.0
> **来源**: 《AI视频生成：打光与金色色彩运用通用方法论》v2.0
> **适用类型**: 产品/建筑/人像/水面/室内空间
> **注入层级**: Stage 11 渲染核心 / 质感提升与空间倍增

---

## 一、光学定义

金色光线在光滑表面发生镜面/漫反射，产生虚拟光源，**扩大金色影响力而不增加金色面积**。

---

## 二、参数规范

| 参数 | 范围 | 调节说明 |
|------|------|----------|
| 反射面材质 | marble(大理石) / water(水面) / glass(玻璃) / metal(金属) / silk(丝绸) | 光滑度越高反射越清晰 |
| 反射强度 | subtle(0.2-0.3) / moderate(0.4-0.6) / strong(0.7-0.9) | 超过0.6易分散注意力 |
| 反射清晰度 | blurred(模糊色块) / soft(柔边) / sharp(清晰镜像) | 模糊=氛围；清晰=精致 |
| 反射色偏 | warm(暖金) / neutral(中性) / cool(冷蓝) | 暖金=统一色调；冷蓝=冷暖对比 |
| 反射面积 | spot(点状) / local(局部) / global(大面积) | 大面积反射可替代部分实体金色 |

## 五、与金色梦境打光的联动

反射映射是金色梦境体系中的"隐藏金色"：

```
联动规则:
1. 反射光作为"环境金" (Ambient Gold) 的延伸
2. 反射强度 0.4-0.6 → 等效增加 5-10% 金色面积感知
3. 大面积反射 → 可替代部分实体金色，保持总面积 < 30%
4. 冷色反射 → 与暖金形成温差对比，增加立体感

示例计算:
- 实体金色面积: 20%
- 反射金色面积: 10% (强度0.5 × 面积20%)
- 感知总金色: 25% (非线性叠加)
- 仍在 30% 安全线内 ✅
```

## 六、问题诊断

| 症状 | 根因 | 纠正 |
|------|------|------|
| 反射过强抢眼 | 反射强度 > 0.6 | 降至 0.3-0.5 |
| 反射破坏极简 | 大面积反射+极简风格 | 反射面积降至 spot，或改用 blurred 清晰度 |
| 反射色偏冲突 | 暖金反射 + 冷蓝环境 | 统一色偏，或明确选择冷暖对比 |
| 反射过于清晰 | 材质光滑度太高 | 改为 soft 或 blurred 清晰度 |
