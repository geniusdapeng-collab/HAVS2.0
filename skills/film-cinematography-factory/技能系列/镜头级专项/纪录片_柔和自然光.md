## 第一部分：柔和自然光的哲学

### 为什么柔和自然光让人觉得"温暖"？

柔和自然光的核心：
- 自然光 = 真实（来自太阳，非人造）
- 柔光 = 温柔（无硬边，无攻击性）
- 暖色 = 治愈（色温3200-4500K，偏暖）
- 结果 = "这个世界是温柔的"

### 柔和自然光的"治愈三定律"

Law 1：自然光 = 真实感
- 人造光 = 控制、刻意、不自然
- 自然光 = 偶然、真实、生活化
- 自然光 = "这是真实发生的"

Law 2：柔光 = 无攻击性
- 硬光 = 对比强烈、戏剧化、紧张
- 柔光 = 过渡自然、温和、舒适
- 柔光 = "我不会伤害你"

Law 3：暖色 = 治愈感
- 冷色 = 医院、科技、疏离
- 暖色 = 家庭、阳光、拥抱
- 暖色 = "这里是安全的"

## 第二部分：柔和自然光的技术执行

### 光源类型

- 窗户光：侧窗、天窗、落地窗（主光源）
- 反光板：白色/银色/金色（补光）
- 柔光布：1/4、1/2、全柔（扩散）
- 黄金时刻：日出/日落前后30分钟（魔法时刻）
- 阴天：天然柔光箱（均匀柔和）

### 技术参数

- 色温：3200K（暖白）- 5600K（日光）
- 对比度：低（1:2 到 1:4）
- 阴影：柔和过渡，无硬边
- 高光：温和，不刺眼
- 方向：侧光/斜射光（有立体感，不平淡）
