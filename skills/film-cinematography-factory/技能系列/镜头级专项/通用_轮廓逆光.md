# 技能：轮廓逆光（Rim Backlight）

> **技能ID**: `lighting-rim-backlight`
> **版本**: v1.0
> **来源**: 《AI视频生成：打光与金色色彩运用通用方法论》v2.0
> **适用类型**: 人像/产品/建筑/风景
> **注入层级**: Stage 11 渲染核心 / 主体分离与神圣感

---

## 一、光学定义

光源位于主体后方 `15°-60°` 范围内，光线仅掠过主体表面，在边缘形成亮度远高于中心的光带。

---

## 二、参数规范

| 参数 | 范围 | 调节说明 |
|------|------|----------|
| 强度 (Intensity) | 0.6 - 1.0 | 人物/产品推荐 0.75-0.9；建筑/风景推荐 0.6-0.75 |
| 色温 (Color Temp) | 4000K - 5500K | 4500K 为最佳通用值，偏暖金而非橙黄 |
| 光源高度 | 主体上方 15° - 45° | 高于视线模拟天光，低于视线模拟水面反射 |
| 光源角度 | 正后方偏左/右 15° - 45° | 完全正后方易产生剪影，偏移增加立体感 |
| 衰减硬度 | 边缘锐利 → 中心柔和 | 硬衰减用于戏剧效果，软衰减用于梦幻效果 |
| 覆盖范围 | 全身/全局/局部 | 全身勾勒用于分离主体，局部点缀用于强调细节 |

### 效果光谱

```
Subtle Rim(0.6) → Elegant Glow(0.75) → Dramatic Halo(0.85) → Sacred Aura(0.95) → Silhouette(1.0)
```

## 五、与漫射柔光的联动

轮廓逆光必须配合漫射柔光使用，否则主体会变成剪影：

```
联动规则:
1. 轮廓逆光强度 : 漫射柔光强度 = 1 : 0.3-0.5
2. 漫射柔光从正面或前侧方提供基础曝光
3. 漫射柔光色温偏冷 (5500K-7500K)，与暖金轮廓形成温差对比
4. 主辅光比控制在 1:1.2 到 1:1.5

错误示例: 只有轮廓逆光 → 剪影效果
正确示例: 轮廓逆光(0.8) + 漫射柔光(0.4) → 分离感+细节保留
```

## 六、问题诊断

| 症状 | 根因 | 纠正 |
|------|------|------|
| 主体变剪影 | 漫射光不足/轮廓光过强 | 增加正面漫射光，或降低轮廓强度 |
| 轮廓光溢出 | 光源角度太平/衰减太软 | 提高光源角度，增加衰减硬度 |
| 边缘发脏 | 色温偏橙黄 | 调整至4500K香槟金，避免橙黄 |
| 轮廓不连贯 | 覆盖范围局部/光源不均匀 | 扩大覆盖范围或增加光源面积 |
