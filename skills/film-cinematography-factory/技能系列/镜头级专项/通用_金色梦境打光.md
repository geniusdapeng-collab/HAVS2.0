# 技能：金色梦境打光（Golden Dream Lighting）

> **技能ID**: `lighting-golden-dream`
> **版本**: v1.0
> **来源**: 《AI视频生成：打光与金色色彩运用通用方法论》v2.0
> **适用类型**: 人像/产品/建筑/风景/抽象
> **注入层级**: Stage 11 渲染核心 / PromptTier 七层架构

---

## 一、核心公式

```
DreamlikeQuality = WhiteBase(60-75%) + GoldAccent(15-25%) + CoolShadow(8-12%) + ParticulateGold(2-5%)
```

**物理原理**：
- **白色/浅灰基底**创造空灵、无限延伸的空间感，模拟人眼在高亮度环境下的散瞳状态
- **金色轮廓光**在边缘产生高斯发光效果，激活视觉皮层V4区（色彩敏感区）
- **冷灰暗部**通过色温对比（暖金 vs 冷灰）制造微妙的立体感
- **微粒金光**在视觉暂留效应中形成动态轨迹，赋予画面时间维度的生命力

## 二、参数规范

### 2.1 金色感知阈值

| 阈值区间 | 感知效果 | 应用建议 |
|----------|----------|----------|
| < 0.15 | 金色几乎不可感知 | 极简风格、隐藏奢华感 |
| **0.15 - 0.35** | **最佳优雅区间** | 高级感、品质感、梦境感（推荐） |
| 0.35 - 0.55 | 金色明显，偏奢华 | 庆典、高端、贵重场景 |
| 0.55 - 0.75 | 金色主导 | 金色产品、艺术装置、特效 |
| > 0.75 | 金色过载 | 避免，除非特殊艺术表达 |

### 2.2 三层金色模型

```
┌─────────────────────────────────────────┐
│ Layer 1: 环境金 (Ambient Gold)           │
│ 饱和度: 10-25% | 明度: 75-90% | 面积: 50-70% │
│ 功能: 氛围基底，定义整体色温倾向            │
│ 心理效应: 温暖、舒适、高级感               │
├─────────────────────────────────────────┤
│ Layer 2: 结构金 (Structural Gold)        │
│ 饱和度: 35-55% | 明度: 55-75% | 面积: 15-25% │
│ 功能: 视觉骨架，引导视线流动               │
│ 心理效应: 品质、价值、精致                │
├─────────────────────────────────────────┤
│ Layer 3: 高光金 (Highlight Gold)         │
│ 饱和度: 55-80% | 明度: 85-100% | 面积: 5-15%  │
│ 功能: 视觉焦点，强调重点                   │
│ 心理效应: 神圣、能量、渴望                │
└─────────────────────────────────────────┘
```

**面积控制铁律**：三层金色总面积不超过画面的 `30%`，超过即触发"土豪金"感知。

## 六、问题诊断速查

| 症状 | 根因分析 | 纠正处方 |
|------|----------|----------|
| 画面发黄发脏 | 金色饱和度太高或面积超限 | 降饱和20%，缩减金色面积至<25% |
| 缺乏梦境感 | 硬光/强阴影/高反差/无雾 | 改用漫射光，阴影区提亮至85%+，添加体积雾 |
| 金色"俗气" | 色相偏橙黄而非香槟金 | 色相+15°红偏移，饱和-15%，明度+10% |
| 画面平无层次 | 缺少冷灰暗部/无温差 | 暗部注入蓝灰(#2C3E50)，确保暖金vs冷灰≥500K温差 |
| 氛围不够高级 | 粒子过多/分布不当 | 粒子密度降半，改为缓慢飘浮，分布侧重中景 |
| 画面偏冷硬 | 白色太纯(#FFF)/色温太高 | 白平衡调至6500K，白中加入5%暖黄(#F5F0E8) |
