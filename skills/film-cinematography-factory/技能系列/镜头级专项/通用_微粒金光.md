# 技能：微粒金光（Particulate Gold）

> **技能ID**: `lighting-particulate-gold`
> **版本**: v1.0
> **来源**: 《AI视频生成：打光与金色色彩运用通用方法论》v2.0
> **适用类型**: 全场景通用（时尚/美食/科技/婚礼/自然）
> **注入层级**: Stage 11 渲染核心 / 空间激活与时间维度

---

## 一、光学定义

悬浮粒子在光路中被照亮产生散射光点，形成**丁达尔效应**的视觉呈现。

---

## 二、参数规范

| 参数 | 范围 | 调节说明 |
|------|------|----------|
| 密度 | sparse / scattered / medium / dense | 低密度=精致；高密度=戏剧性 |
| 粒径分布 | dust-like(微尘) / pollen(花粉) / sparkle(闪光) / bokeh(散景) | 微尘=写实；闪光=魔幻；散景=梦幻 |
| 运动状态 | static(静止) / floating(漂浮) / rising(上升) / swirling(旋转) | 漂浮=宁静；上升=神圣；旋转=能量 |
| 发光模式 | lit-only(仅被照亮) / self-glow(自发光) / both(混合) | 仅照亮=写实；自发光=超现实 |
| 分布深度 | foreground(前) / midground(中) / background(后) / full(全纵深) | 全纵深=最强空间感 |

### 空间分布公式

```
OptimalDistribution = Foreground(20%) + Midground(50%) + Background(30%)
```

## 五、与体积光的联动

微粒金光与体积光（`lighting-volumetric-godrays`）天然联动：

```
联动规则:
1. 体积光提供"光路"，微粒在光路中可见
2. 介质密度决定微粒可见度：高密度介质 = 高可见度
3. 光束方向决定微粒运动方向：上升光束 → 上升微粒
4. 多束光柱 → 微粒在多个光路中分布，空间感倍增

参数联动:
- 体积光强度 0.7+ → 自动提升金色感知阈值至 0.25-0.35
- 高密度介质 → 自动增加环境金面积至 60-70%
- 多束光柱 → 自动启用结构金引导视线
```

## 六、问题诊断

| 症状 | 根因 | 纠正 |
|------|------|------|
| 画面发灰 | 粒子密度过高 | 密度降至 sparse 或 scattered |
| 干扰主体 | 粒子在主体区域过多 | 粒子避开主体区域，分布侧重中后景 |
| 运动太急 | 粒子速度过快 | 改为 slow floating / gentle rising |
| 缺乏空间感 | 粒子分布单一 | 按前20% + 中50% + 后30%分布 |
