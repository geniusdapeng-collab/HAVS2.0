# 技能：体积光与上帝光（Volumetric God Rays）

> **技能ID**: `lighting-volumetric-godrays`
> **版本**: v1.0
> **来源**: 《AI视频生成：打光与金色色彩运用通用方法论》v2.0
> **适用类型**: 室内/森林/水下/废墟/舞台/建筑
> **注入层级**: Stage 11 渲染核心 / 视觉氛围增强

---

## 一、光学定义

当光束穿过含有散射介质（雾、尘、水气）的空气时，由于**米氏散射（Mie Scattering）**形成可见的光柱。

---

## 二、参数规范

| 参数 | 范围 | 调节说明 |
|------|------|----------|
| 光源开口 | 云层间隙 / 窗户 / 天井 / 树冠间隙 | 开口越小，光束越锐利；开口越大，光越漫散 |
| 光束方向 | 垂直(80°-90°) / 斜射(45°-60°) | 垂直=天恩降临感；斜射=时间感（晨昏） |
| 介质密度 | low / medium / high | 低密度=隐约光束；高密度=浓密光柱 |
| 光束数量 | 1-5 束 | 单束=聚焦；多束=宏大；散射=氛围 |
| 颜色渐变 | 顶部纯白 → 中部淡金 → 底部暖金 | 模拟大气散射的颜色偏移 |
| 粒子可见度 | subtle / visible / dense | 与介质密度联动 |

### 效果光谱

```
Subtle Haze(雾感散射) → Soft Beams(柔和光柱) → Dramatic Shafts(戏剧性光柱) → Divine Rain(光雨倾泻) → Blinding Glory(强光夺目)
```

## 五、与金色梦境打光的联动

当同时使用 `lighting-golden-dream` 和 `lighting-volumetric-godrays`：

```
优先级规则:
1. 体积光作为"结构金" (Structural Gold) 的载体
2. 光束边缘自然形成金色轮廓光 (Rim Light)
3. 介质中的粒子自动激活"微粒金光" (Particulate Gold)
4. 漫射环境光由体积光的散射提供

联动参数:
- 体积光强度 0.7+ → 自动提升金色感知阈值至 0.25-0.35
- 高密度介质 → 自动增加环境金面积至 60-70%
- 多束光柱 → 自动启用结构金引导视线
```

## 六、问题诊断

| 症状 | 根因 | 纠正 |
|------|------|------|
| 光柱不自然 | 光源位置不合理/无介质 | 确保有可见开口+散射介质(雾/尘) |
| 光束过于生硬 | 开口过小/介质过少 | 增大开口或增加介质密度 |
| 画面发灰 | 介质密度过高 | 降低雾密度，或放弃清晰反射 |
| 光柱颜色单调 | 缺少渐变 | 顶部纯白→中部淡金→底部暖金 |
