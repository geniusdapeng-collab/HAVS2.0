# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-29

### Added
- Multi-Agent orchestration with 8 specialized AI agents
- 25-field cinematic shot language standardization
- Stability Shields: StabilityShield, BaselineRegistry, HealthMonitor, LLMGateway
- Phase Architecture for modular production pipeline
- LLM Reasoning Engine with O(n) JSON extraction
- Graceful Shutdown handling
- Process Guard for rejection absorption
- Creative Intensity Engine (L0-L5 levels)
- MCP Server adapter for AI agent integration
- Claude Code plugin manifest (.claude-plugin/plugin.json)
- OpenClaw skill manifest (.openclaw/skill.json)
- ROADMAP.md for project planning
- CI/CD pipeline configuration (GitHub Actions)
- SECURITY.md and CONTRIBUTING.md
- Bilingual documentation (English + Chinese)

### Fixed
- SIGKILL root cause: O(n²) JSON extraction replaced with O(n) stack-based algorithm
- Memory leaks in long-running production pipelines
- Race conditions in multi-agent coordination

### Changed
- Production pipeline optimized for AI agent orchestration
- Field standardization aligned with Hollywood cinematic practices
